# 🧮 Simple-Calculator

## 📝 Description
A simple calculator application written in Python that performs basic arithmetic operations. This project was forked from [charanramagiri/Simple-Calculator](https://github.com/charanramagiri/Simple-Calculator).

## ✨ Features
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and simple interface
- Error handling for invalid inputs
- Easy to use and understand

## 🛠️ Technologies Used
- Python 100%

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system

### Installation
1. Clone the repository:
```bash
git clone https://github.com/sainikith07/Simple-Calculator.git
```

2. Navigate to the project directory:
```bash
cd Simple-Calculator
```

3. Run the calculator:
```bash
python calci.py
```

## 💻 Usage
1. Launch the application
2. Enter the first number
3. Choose the operation (+, -, *, /)
4. Enter the second number
5. View the result

## 📂 File Structure
- `calci.py` - Main calculator script containing the calculator logic
